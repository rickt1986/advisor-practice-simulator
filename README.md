# 顾问智能工作台（公开体验版）

这是一个 K12 顾问新人陪练与实时建议系统。公开体验版使用本地场景化家长模拟，不上传业务对话、不暴露模型密钥。

## 公开体验版

GitHub Pages 仅发布 `index.html`、`styles.css` 与 `app.js`，可供外部体验陪练流程、评分与复盘闭环。因密钥安全，公开版不调用 Kimi。

## 线上正式环境

线上正式服务部署在 `advisor.yfspp.com`。模型密钥只存放在服务器私有环境文件中，由 Node 服务端读取；浏览器与 GitHub 仓库均不保存密钥。服务端以独立 PM2 进程运行，通过 Nginx 反向代理并限制单 IP 的接口调用频率。

## 本地完整模式

在本目录运行：

```bash
node server.js
```

然后在浏览器访问 `http://localhost:8080`。

## 已实现

- 6 个 K12 顾问高频家长场景；
- 家长会基于顾问回复继续追问；
- 至少完成 3 次顾问回复、共情承接、关键诊断与具体下一步，才允许结束评分；建议最多 6 次顾问回复；
- 结束后按共情承接、需求诊断、下一步推进、合规表达评分；
- 拦截效果承诺、焦虑营销、虚假稀缺和施压式表达；
- 每个场景都有可执行的参考改写。

## 启用正式大模型家长

服务端当前使用 Kimi Coding 的 Anthropic 兼容接口。密钥只在服务端环境变量或本机 Kimi Coding 配置中读取，不会被复制到本项目。**不要把密钥写进浏览器代码或提交到仓库**：

```bash
export KIMI_CODING_API_KEY="你的 Kimi Coding 密钥"
export KIMI_CODING_MODEL="kimi-code"
node server.js
```

可选设置 `KIMI_CODING_BASE_URL` 覆盖接口地址。未配置有效密钥时，系统自动保留规则家长模式。
